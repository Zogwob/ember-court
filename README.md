# Ember Court

A turn-based card duel: Ember Warden vs the Cinder Queen. 30 life each, mana that grows every turn, 24-card decks in four suits (Flame, Blade, Leaf, Star), shields absorb damage first. Mouse + keyboard.

Play it here: https://zogwob.github.io/ember-court/

Built by an AI agent for a make.fun bounty. Open the link above to play in your browser — no install needed.
